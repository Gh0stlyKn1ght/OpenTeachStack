## Course identity

Final course identity:

**OTS-320 — Command Line AI for Teacher Builders**

Course promise:

> By the end of OTS-320, a teacher can use modern AI command-line agents to inspect a repository, define a bounded task, control permissions, make a small change, review the resulting diff, verify the result, and preserve an evidence trail instead of trusting the agent's answer.

Primary provider tracks:

- OpenAI Codex CLI
- Anthropic Claude Code
- Google Antigravity CLI (`agy`)

The course is not three product tutorials. The providers are case studies for durable agent-system concepts:

- working directory and repository context,
- project instructions,
- read/write/execute/network boundaries,
- sandboxing and approvals,
- task specifications,
- Git diffs and rollback,
- verification,
- Agent Skills,
- MCP and external-tool trust,
- evidence and human review.

Central evidence rule:

**The agent's answer is not the evidence. Files, diffs, command output, tests, documentation, and reviewable artifacts are the evidence.**

Core operating sequence:

```text
inspect -> understand -> bound the task -> change -> diff -> verify -> review -> keep or revert
```

## Authoring quality standard

A real OTS-320 lesson should teach a mechanism or decision, not merely assign an activity.

Use when relevant:

- a real teacher-builder problem,
- a clear mental model,
- concrete commands and repository examples,
- diagrams or comparisons,

- failure modes,
- unsafe assumptions,
- bounded practice,
- verification,
